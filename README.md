#  Resume Skill Analyzer

##  Project Description
Resume Skill Analyzer is a Python-based project that extracts skills from PDF resumes, calculates a skill score, and compares multiple resumes to evaluate candidates. It helps in identifying skill gaps and improving resume quality for internships and jobs.

##  Features
- Extract text from PDF resumes  
- Identify key technical and soft skills  
- Generate resume skill score  
- Compare two resumes  
- Show missing skills for improvement  

## ▶️ How to Run This Project

1. Clone the repository:
   git clone https://github.com/your-username/resume-skill-analyzer.git
2. Open the notebook:
   Resume_Skill_Analyzer.ipynb
3. Run all cells step by step
4. Upload your PDF resume when prompted
5. View extracted skills, score, and comparison results

## How It Works
1. Upload PDF resume(s)  
2. Extract text using PyPDF2  
3. Match skills from predefined skill list  
4. Calculate score based on matched skills  
5. Compare two resumes (optional feature)
